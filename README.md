# PhoneGet бот — автоматизация @phonegetcardsbot / @phonegetroulettebot

Мультиаккаунтный бот на **pyrofork**. Управление — через **управляющего Telegram-бота**
с инлайн-кнопками. По каждому аккаунту:

- 🃏 `Ткарточка` → @phonegetcardsbot, сам ловит кулдаун из ответа и шлёт по таймеру.
- 🎰 `Рулетка` → @phonegetroulettebot, жмёт «Крутить», планирует по кулдауну.
- ⛏ В заданное время по МСК — `Тмайнинг` → «Снять деньги с фермы», следом 🎁 `Ежедневная награда` → «Забрать».
- 💸 После майнинга авто-вывод очков: `такк` → `Точки: N` → `/pay <получатель> N` → «Подтвердить».
- 🔄 Слив телефонов получателю (координированный трейд), повтор пока коллекция не опустеет.
- 🧩 Произвольные задачи: любой бот, любой текст, своё расписание (интервал или ежедневно).
- ⭐ Пуш-метка в статусе при «хорошем» телефоне (фантом).

Получателей (для вывода очков и для трейда) **каждый пользователь задаёт сам**,
на каждый свой аккаунт отдельно — ничего не назначается автоматически.

## Установка

```powershell
python -m pip install -r requirements.txt
# только для локального запуска в трее на Windows (tray.py):
python -m pip install -r requirements-desktop.txt
```

## Настройка `settings.json`

```json
{
  "api_id": 12345, "api_hash": "...", "bot_token": "ТОКЕН_@BotFather",
  "admin_ids": [ТВОЙ_TG_ID],
  "multi_user": true,
  "default_card_interval": 3600, "default_roulette_interval": 86400,
  "good_phone_keywords": ["фантом", "phantom"],
  "report_time": "00:00", "payout_delay": 120
}
```

Тонкая настройка трейда — блок `trade` (подписи кнопок/маркеры, `repeat_threshold`,
`action_delay`, `solo_accept_timeout`); по умолчанию всё уже задано.

### Альтернатива: переменные окружения (для облачного хостинга)
Вместо `settings.json` основные поля можно задать переменными окружения — они
имеют приоритет над файлом. Так секреты не лежат в файле на сервере:

| Переменная | Соответствует полю |
|---|---|
| `BOT_TOKEN` | `bot_token` |
| `API_ID` | `api_id` |
| `API_HASH` | `api_hash` |
| `ADMIN_IDS` | `admin_ids` (через запятую: `111,222`) |
| `MULTI_USER` | `multi_user` (`true`/`false`) |
| `MAIN_ACCOUNT_ID` | `main_account_id` |
| `DEFAULT_CARD_INTERVAL` | `default_card_interval` |
| `DEFAULT_ROULETTE_INTERVAL` | `default_roulette_interval` |
| `REPORT_TIME` | `report_time` |
| `PAYOUT_DELAY` | `payout_delay` |
| `DATA_DIR` | где лежат `settings.json`/`accounts.json` (по умолчанию — папка проекта) |

Вложенные блоки (`trade`, `containers`, `self_commands`, `good_phone_keywords`) через
env не задаются — у них уже есть рабочие дефолты; если нужно потоньше — используй
`settings.json` (можно сочетать: часть через env, часть файлом).

## Запуск

- `run.bat` — в трее без консоли (значок у часов: «Открыть лог» / «Выход»).
- `run_console.bat` — видимая консоль с логами (для отладки).
- Логи всегда пишутся в `bot.log`.

Затем открой управляющего бота в Telegram → `/start`.

## Мультипользовательский режим

`"multi_user": true` в `settings.json` — бот открыт **всем**: любой пишет ему `/start`,
добавляет свои аккаунты и настраивает их, **видя только свои** (изоляция по владельцу).
Никаких автоматических получателей — при `"multi_user": false` доступ только у `admin_ids`.

> ⚠️ В открытом режиме любой, кто знает бота, использует ресурсы твоего ПК/сервера
> (фарм идёт от их аккаунтов). Чужие аккаунты друг другу не видны и недоступны.

## Управление (кнопки)

- **📋 Аккаунты** — список (🟢/🔴) + «➕ По номеру / ➕ Session».
- **Карточка аккаунта** → подменю:
  - **🎯 Получатели** — свой получатель `/pay` (вывод очков) и свой получатель трейда:
    `@username` или числовой id, вводишь сам. Пока не задано — авто-вывод/авто-трейд
    просто ничего не делают (никакого автоматического адресата). Кнопка «👑 Сделать
    получателем для всех моих аккаунтов» — быстро назначить этот аккаунт получателем
    для остальных твоих аккаунтов (явное действие, не происходит само по себе).
  - **⚙️ Автоматизация** — карточки / рулетка / майнинг / авто-вывод / авто-трейд.
  - **⏱ Интервалы** — интервалы карточек/рулетки + время майнинга (ЧЧ:ММ МСК).
  - **🧩 Задачи** — свои произвольные задачи: кому слать (@бот), что писать, когда
    (интервал в секундах ИЛИ ЧЧ:ММ ежедневно по МСК) и опц. какую кнопку нажать после.
  - **▶️ Действия** — «Собрать майнинг сейчас», «Слить телефоны».
  - ⏸/▶️ общий вкл/выкл, ✏️ имя, 🗑 удалить.

### Что будет, если включить авто-трейд на всех аккаунтах сразу
Если несколько твоих фармов настроены на **одного и того же** локально управляемого
получателя (например, все шлют на один «сборочный» аккаунт) и их майнинг срабатывает
одновременно — они **встают в очередь** и обмениваются по одному, а не ломаются и не
бьются друг с другом (получатель физически может вести только один обмен разом).
Если у фармов **разные** получатели — эти обмены идут полностью параллельно, очередь
их не касается.

### 🎯 Получатель трейда: свой аккаунт или произвольный
- Если в «Трейд» указан **другой твой аккаунт**, тоже подключённый к боту (по @username
  или id) — обмен идёт **полностью автоматически с обеих сторон** (обе стороны сами жмут
  Готов/Подтвердить).
- Если указан **любой другой** `@username`/id (не подключён к боту) — бот автоматизирует
  только сторону фарма (открывает трейд, добавляет телефоны, жмёт Готов и Подтвердить);
  получателю нужно самому принять предложение и завершить обмен на своей стороне.

### 🧩 Произвольные задачи
Кроме встроенных (карточки/рулетка/майнинг) можно задать любые отправки:
«🧩 Задачи → ➕ Добавить задачу» → @username бота → текст → расписание
(`3600` = каждые 3600с, либо `09:30` = ежедневно в 09:30 МСК) → текст кнопки (или `-`).
Задачу можно вкл/выкл, «Запустить сейчас», удалить.

> Фото-капчи бот не решает и решать не будет (это анти-бот защита) — но задачу
> «отправить команду по расписанию» под неё завести можно, просто капчу отвечает человек.

### 📦 Магазин контейнеров
`⚙️ Автоматизация → 📦 Магазин контейнеров`: шлёт «Магазин контейнеров» боту
@phonegetcardsbot. Если ответ — стандартное «раскуплены, следующая поставка через X
дн. Y ч. Z мин.» — бот сам ждёт это время и проверяет снова. Если ответ **другой**
(похоже, контейнеры в наличии / появилась капча) — бот **не жмёт кнопки вслепую**, а
шлёт тебе (владельцу аккаунта) личное сообщение с текстом из `containers.captcha_alert_text`
(по умолчанию «КАПЧА») и превью ответа, чтобы ты разобрался вручную. Ручная проверка —
кнопка «📦 Проверить магазин контейнеров» в «▶️ Действия».
Настройки — `settings.json → containers` (целевой бот, маркер «распродано», текст алерта).

### 🎁 Ежедневная награда
Собирается автоматически **вместе с майнингом** (тот же триггер по времени, `mining_time`),
но включается отдельным тогглом `⚙️ Автоматизация → 🎁 Ежедневная награда`. Шлёт
«Ежедневная награда» → жмёт «Забрать ✅».

### 💬 Команды `.trade` / `.pay` прямо в переписке
`⚙️ Автоматизация → 💬 Команды .trade/.pay в личках` (вкл по умолчанию). Аккаунт следит
за СВОИМИ же исходящими сообщениями в личных чатах: если ты (с телефона, с другого
устройства, залогиненного в тот же аккаунт) пишешь собеседнику `.trade` или
`.pay 505050`, бот сам отправляет @phonegetcardsbot `/trade @собеседник` или
`/pay @собеседник 505050` — получатель берётся из того, кому ты это написал.
Сообщения с игровыми ботами (карточки/рулетка) не перехватываются. Команды и шаблоны —
`settings.json → self_commands` (можно добавить свои). Если бот в ответ попросит
подтверждение кнопкой «Подтвердить» (как у `/pay`) — она нажимается автоматически.

## ☎️ Узнать номер телефона аккаунта
Сессия в боте уже авторизована в Telegram — SMS-код для этого не нужен, номер
читается напрямую через API (`get_me()`). Полезно, если потерял доступ к номеру
(сменил телефон/SIM), но сессия в боте ещё жива.
- **▶️ Действия → ☎️ Показать номер телефона** — для одного аккаунта.
- **📋 Мои аккаунты → ☎️ Показать все номера** — сразу по всем твоим запущенным
  аккаунтам одним списком.

⚠️ Это не восстанавливает потерянный номер физически — просто показывает, какой
номер привязан к аккаунту, пока сессия работает. Смени email/2FA/номер в настройках
Telegram (через тот же бот можно добавить кнопку позже), пока сессия не истекла.

## 📨 Последние сообщения аккаунта
Кнопка «📨 Сообщения» в карточке аккаунта — постоянно ведущийся лог последних ~30
сообщений на этом аккаунте (входящие 🔽 и исходящие 🔼, из любых чатов, не только
игровых ботов), показывает последние 15 с чатом/текстом/временем. «🔄 Обновить»
подтягивает свежие.

## Быстрый /start
После `/start` внизу экрана закрепляется постоянная кнопка **`/start`** — не нужно
каждый раз набирать команду вручную, один тап и панель открывается заново.

## Добавить / перелогинить аккаунт

- В боте: 📋 Аккаунты → ➕ По номеру (api_id → api_hash → телефон → код → 2FA) или ➕ Session.
- Без бота (если сессия слетела): `python relogin.py` (останови бота перед этим).

## Автозапуск Windows

- `autostart_install.bat` — двойной клик, добавляет ярлык в «Автозагрузку» (старт в трее при входе).
- `autostart_uninstall.bat` — убрать.

## Файлы

| Файл | Назначение |
|------|-----------|
| `main.py` | точка входа |
| `controlbot.py` | управляющий бот (кнопки, добавление аккаунтов) |
| `manager.py` | менеджер воркеров + трейд с повтором |
| `automation.py` | логика аккаунта (карточки/рулетка/майнинг/вывод) |
| `trade.py` | координированный обмен |
| `storage.py` | settings.json / accounts.json |
| `tray.py` | значок в трее (свою иконку — файлом `icon.ico`) |
| `relogin.py` | перелогин/добавление из консоли |
| `run.bat` · `run_console.bat` · `start_hidden.vbs` · `autostart_*.bat` | запуск/автозапуск |

⚠️ `accounts.json` хранит session string (полный доступ к аккаунтам), `settings.json` —
токен бота. Оба в `.gitignore` — не делись ими.

> `TgCrypto is missing` в логах — не ошибка, бот работает и без него (просто медленнее шифрует).
