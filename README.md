# PhoneGet бот — автоматизация @phonegetcardsbot / @phonegetroulettebot

Бот-помощник на **pyrofork** для игры **PhoneGet** в Telegram. Управление — через
своего же управляющего Telegram-бота с инлайн-кнопками. Четыре **независимых модуля**,
каждый включается/выключается отдельно:

- 🌾 **Фарм карточек** — карточки, рулетка, майнинг, ежедневная награда, магазин
  контейнеров, вывод очков, трейд.
- 📨 **Автоотправка** — произвольные задачи по расписанию (любой бот, любой текст) +
  быстрые команды `.trade`/`.pay`, напечатанные прямо в переписке.
- 🏪 **Магазин телефонов** — автозакупка (ручная кнопка + автоматизация по расписанию).
- 🛠 **Мастерская** — автопочинка своих нерабочих телефонов (только своим оборудованием)
  и автопринятие чужих заказов на ремонт (с тихими часами, чтобы не конкурировать за
  оборудование по ночам).

## 🔐 Как это устроено с точки зрения безопасности

Каждый аккаунт логинится **своей же сессией**, которую видит и держит только тот, кто
её создал. Бот **не хранит чужие сессии централизованно** и не предлагает «войдите
через меня, я подержу ваш аккаунт у себя» — это разворачивается один раз кем-то (тобой
или любым другим человеком) как **свой собственный** инстанс, и в него добавляются
только свои же аккаунты.

Session string = полный доступ к аккаунту (чтение/отправка сообщений от его имени).
Добавляй сюда только тот аккаунт, которым управляешь лично ты. Бот сознательно **не
читает** контакты, историю чужой переписки и (в актуальной версии) номер телефона —
только то, что нужно для игровой логики и автоотправки.

## 🚀 Быстрый старт (свой инстанс за ~10 минут)

1. **Форкни / склонируй репозиторий** себе.
2. Получи `api_id`/`api_hash` на [my.telegram.org](https://my.telegram.org) и токен
   бота у [@BotFather](https://t.me/BotFather).
3. Разверни на [Railway](https://railway.app) (или любом хостинге с Python):
   - Подключи репозиторий, добавь **Volume** (постоянный диск) — иначе аккаунты будут
     слетать при каждом передеплое.
   - Задай переменные окружения: `BOT_TOKEN`, `API_ID`, `API_HASH`, `ADMIN_IDS`,
     `DATA_DIR=/data` (путь монтирования тома) — см. таблицу ниже.
   - Старт-команда: `python main.py` (уже прописана в `railway.json`).
4. Открой своего бота в Telegram → `/start` → добавь свой первый аккаунт.

Локально — то же самое, но без хостинга: см. «Установка» ниже.

## Установка (локально)

```powershell
python -m pip install -r requirements.txt
# только для локального запуска в трее на Windows (tray.py):
python -m pip install -r requirements-desktop.txt
```

## Настройка `settings.json`

```json
{
  "api_id": 12345, "api_hash": "...", "bot_token": "ТОКЕН_@BotFather",
  "admin_ids": [ТВОЙ_TG_ID],
  "multi_user": true,
  "default_card_interval": 3600, "default_roulette_interval": 86400,
  "good_phone_keywords": ["фантом", "phantom"],
  "report_time": "00:00", "payout_delay": 120
}
```

Тонкая настройка трейда — блок `trade` (подписи кнопок/маркеры, `repeat_threshold`,
`action_delay`, `solo_accept_timeout`); по умолчанию всё уже задано.

Так же по умолчанию уже задано: `phone_shop` (магазин телефонов — команда открытия,
подписи кнопок «купить оптом»/«подтвердить», `check_interval`) и `repair` (мастерская —
команды/подписи кнопок, `check_interval`, `quiet_start`/`quiet_end` тихих часов
автопринятия). Если что-то из этого не совпадёт с реальными текстами игры — правится
в `settings.json`, без изменения кода (см. «📦 Магазин контейнеров» ниже — тот же принцип).

### Альтернатива: переменные окружения (для облачного хостинга)
Вместо `settings.json` основные поля можно задать переменными окружения — они
имеют приоритет над файлом. Так секреты не лежат в файле на сервере:

| Переменная | Соответствует полю |
|---|---|
| `BOT_TOKEN` | `bot_token` |
| `API_ID` | `api_id` |
| `API_HASH` | `api_hash` |
| `ADMIN_IDS` | `admin_ids` (через запятую: `111,222`) |
| `MULTI_USER` | `multi_user` (`true`/`false`) |
| `MAIN_ACCOUNT_ID` | `main_account_id` |
| `DEFAULT_CARD_INTERVAL` | `default_card_interval` |
| `DEFAULT_ROULETTE_INTERVAL` | `default_roulette_interval` |
| `REPORT_TIME` | `report_time` |
| `PAYOUT_DELAY` | `payout_delay` |
| `DATA_DIR` | где лежат `settings.json`/`accounts.json` (по умолчанию — папка проекта; на Railway — точка монтирования Volume, напр. `/data`) |

Вложенные блоки (`trade`, `containers`, `self_commands`, `good_phone_keywords`) через
env не задаются — у них уже есть рабочие дефолты; если нужно потоньше — используй
`settings.json` (можно сочетать: часть через env, часть файлом).

## Запуск

- `run.bat` — в трее без консоли (значок у часов: «Открыть лог» / «Выход»). Только Windows.
- `run_console.bat` — видимая консоль с логами (для отладки). Только Windows.
- На сервере/Linux/Railway: просто `python main.py`.
- Логи всегда пишутся в `bot.log`.

Затем открой управляющего бота в Telegram → `/start`.

## Мультипользовательский режим

`"multi_user": true` в `settings.json` — бот открыт **всем**: любой пишет ему `/start`,
добавляет свои аккаунты и настраивает их, **видя только свои** (изоляция по владельцу).
Никаких автоматических получателей — при `"multi_user": false` доступ только у `admin_ids`.

> ⚠️ В открытом режиме любой, кто знает бота, использует ресурсы твоего ПК/сервера
> (фарм идёт от их аккаунтов). Чужие аккаунты друг другу не видны и недоступны. Это
> НЕ то же самое, что «хранение чужих сессий» — каждый добавляет и логинит **свой**
> аккаунт сам, ты просто предоставляешь вычислительные мощности.

## Управление (кнопки)

- **📋 Мои аккаунты** — список (🟢/🔴, у 👑 главного — корона перед именем) + «➕ По
  номеру / ➕ Session».
- **Карточка аккаунта** — свёрнутая: только «через сколько что» по фичам, которые
  СЕЙЧАС включены (🃏 карточка / 🎰 рулетка, если включена / ⛏ майнинг / 📦 конты) —
  выключенная фича просто не показывается. Дальше — независимые разделы:

  ### 🌾 Фарм карточек
  - ⏸/▶️ вкл/выкл всего модуля разом.
  - **⚙️ Автоматизация** — карточки / рулетка / майнинг / ежедневная награда /
    авто-вывод / авто-трейд / магазин контейнеров, каждое отдельным тумблером.
  - **⏱ Интервалы** — интервалы карточек/рулетки + время майнинга (ЧЧ:ММ МСК).
  - **🎯 Получатели** — свой получатель `/pay` (вывод очков) и свой получатель трейда:
    `@username` или числовой id, вводишь сам (без `@` — бот сам добавит, если это не
    цифры). Пока не задано — авто-вывод/авто-трейд просто ничего не делают (никакого
    автоматического адресата). Кнопка «👑 Сделать получателем для всех моих аккаунтов» —
    явное разовое действие, копирует **числовой id** источника (если известен — это
    надёжнее username, который можно сменить/потерять), иначе `@username`.
  - **▶️ Действия** — «Собрать майнинг сейчас», «Слить телефоны», «Проверить магазин»,
    «💸 Перевести человеку» (разово вводишь @username/id + сумму очков — бот сам шлёт
    `/pay` с этого аккаунта, независимо от настроенного получателя вывода — удобно для
    твинков), «🤝 Трейд с человеком» (то же самое, но разовый трейд на произвольного
    получателя вместо настроенного 🎯 получателя трейда).
  - На 👑 **главном аккаунте** (см. ниже) в «▶️ Действия» есть ещё «💰 Сумма слива
    твинкам» (задать фикс. сумму очков на твинка) и «💧 Слить твинкам сейчас» —
    вручную, обычно перед контами: главный аккаунт шлёт `/pay` на эту сумму каждому
    ДРУГОМУ своему аккаунту (по числовому id, если известен, иначе @username).

  ### 📨 Автоотправка
  - ⏸/▶️ вкл/выкл всего модуля разом.
  - **🧩 Мои задачи** — свои произвольные задачи: кому слать (@бот), что писать, когда
    (интервал в секундах ИЛИ ЧЧ:ММ ежедневно по МСК) и опц. какую кнопку нажать после.
  - **💬 Команды .trade/.pay в личках** — свой тумблер.

  ### 🛠 Мастерская и магазин
  - **🛠 Автопочинка своих телефонов** — тумблер. Раз в `repair.check_interval` секунд
    (по умолчанию 300) находит первый нерабочий телефон с ещё не отданной в ремонт
    поломкой и чинит её **только своим оборудованием** («В своей мастерской (Бесплатно)»)
    — чужие мастерские никогда не арендует, даже если своего инструмента для этой
    поломки сейчас не хватает (тогда просто пропускает до следующего прохода).
  - **📥 Автопринятие чужих заказов** — тумблер. Когда от игры приходит запрос «Вам
    пришёл запрос на ремонт телефона... от клиента...», бот сам жмёт «✅ Принять заказ»,
    если в мастерской есть свободное место (`Занято ремонтом: X/N`) и сейчас НЕ тихие
    часы. **Тихие часы** — `repair.quiet_start`..`repair.quiet_end` (по умолчанию
    22:00–07:00 по Тбилиси): в это время автопринятие ничего не нажимает — заказ просто
    истечёт сам (через час игра вернёт телефон клиенту) — так автопринятие не отжимает
    оборудование у автопочинки по ночам.
  - **🏪 Автозакупка телефонов** — тумблер + настройки «Редкость закупки» (по умолчанию
    Ширпотреб) и «Кол-во за раз» (0 = максимум предложенного в рамках баланса, либо
    конкретное число). Без настройки модели берёт первую в списке выбранной редкости.
    Покупает через «Купить оптом», раз в `phone_shop.check_interval` секунд (по
    умолчанию 3600).
  - Ручные кнопки: «🛠 Почистить нерабочие сейчас», «🏪 Купить телефоны сейчас».

- ⏸/▶️ общий вкл/выкл (весь аккаунт целиком), ✏️ имя, 🗑 удалить.

Модули **полностью независимы**: можно держать включённым только Фарм, только
Автоотправку, только Мастерскую/Магазин, или всё сразу — они не мешают друг другу и
живут в разных файлах (`farm.py` / `autosend.py` / `shop.py` / `repair.py`).

### Что будет, если включить авто-трейд на всех аккаунтах сразу
Если несколько твоих фармов настроены на **одного и того же** локально управляемого
получателя (например, все шлют на один «сборочный» аккаунт) и их майнинг срабатывает
одновременно — они **встают в очередь** и обмениваются по одному, а не ломаются и не
бьются друг с другом (получатель физически может вести только один обмен разом).
Если у фармов **разные** получатели — эти обмены идут полностью параллельно, очередь
их не касается.

### 🎯 Получатель трейда: свой аккаунт или произвольный
- Если в «Трейд» указан **другой твой аккаунт**, тоже подключённый к боту (по @username
  или id) — обмен идёт **полностью автоматически с обеих сторон** (обе стороны сами жмут
  Готов/Подтвердить).
- Если указан **любой другой** `@username`/id (не подключён к боту) — бот автоматизирует
  только сторону фарма (открывает трейд, добавляет телефоны, жмёт Готов и Подтвердить);
  получателю нужно самому принять предложение и завершить обмен на своей стороне.

### 🧩 Произвольные задачи (модуль Автоотправка)
Кроме встроенного фарма можно задать любые отправки:
«📨 Автоотправка → 🧩 Мои задачи → ➕ Добавить задачу» → @username бота → текст →
расписание (`3600` = каждые 3600с, либо `09:30` = ежедневно в 09:30 МСК) → текст кнопки
(или `-`). Задачу можно вкл/выкл, «Запустить сейчас», удалить.

> Фото-капчи бот не решает и решать не будет (это анти-бот защита) — но задачу
> «отправить команду по расписанию» под неё завести можно, просто капчу отвечает человек.

### 📦 Магазин контейнеров
`🌾 Фарм → ⚙️ Автоматизация → 📦 Магазин контейнеров`: открывает магазин командой
`containers.open_command` (по умолчанию `/tcontainershop`) у @phonegetcardsbot и разбирает,
что пришло в ответ:
- **«раскуплены, следующая поставка через X дн. Y ч. Z мин.»** — просто ждёт это время
  и проверяет снова, как и раньше.
- **Магазин открыт** (меню с категориями «Бюджетный/Дорогой/Донатный контейнеры») —
  бот сам покупает: заходит в категорию → смотрит «Вы можете купить ещё N шт.» →
  если N=1 жмёт «Купить 1 шт.», иначе «Купить оптом» и выбирает максимальное доступное
  количество → подтверждает покупку («✅ Подтвердить»), если бот её спрашивает. Так по
  очереди для каждой разрешённой категории (порядок — `containers.preferred_categories`,
  по умолчанию Донатный → Дорогой → Бюджетный).
  Какие категории покупать **для конкретного аккаунта** — тумблеры в
  `⚙️ Автоматизация → 📦 Какие категории покупать` (по умолчанию все три включены).
- **Анти-бот капча** (картинка с примером типа «10+15», просит решить и написать ответ
  цифрами в чат, попыток обычно мало) — бот её **не решает** и, что важно, **не долбит
  магазин повторно** (повторное открытие может сжечь оставшиеся попытки капчи). Вместо
  этого шлёт тебе через управляющего бота интерактивный алерт с текстом из
  `containers.captcha_alert_text` (по умолчанию «КАПЧА») и кнопками выбора категории
  (🎁 Донатный / 💎 Дорогой / 💰 Бюджетный / ✅ Как настроено / ⏭ Пропустить). Ты решаешь
  капчу вручную прямо в чате с игровым ботом, а затем жмёшь одну из кнопок в алерте —
  это разово пробует открыть магазин заново и, если получилось, покупает выбранную
  категорию первой (или в обычном порядке, если жал «Как настроено»). Пока ты не нажал
  кнопку — автоматизация магазин не трогает.
- **Бот не отвечает** (НЕ капча, а просто нет ответа) — на рестоке контейнеров игровой
  бот часто перегружен (много желающих), это отдельный случай, где ретраить безопасно:
  автоматизация **не сдаётся после одной попытки** и повторяет открытие магазина каждые
  `containers.retry_interval` секунд (по умолчанию 10) в течение `containers.retry_window`
  секунд (по умолчанию 600) ПОСЛЕ расчётного времени рестока, и точно так же переповторяет
  клики внутри самой покупки, если бот перестаёт отвечать посреди процесса.
- Совсем незнакомый ответ — как и с капчей, бот не жмёт кнопки вслепую, а зовёт владельца
  тем же интерактивным алертом.

**Ранний старт вместо холодного удара ровно в рестоке.** Игра сама говорит, через сколько
будет новая поставка («раскуплены, следующая через X») — но именно в момент X игровой бот
перегружен и не отвечает (слишком много желающих одновременно). Поэтому за
`containers.early_start` секунд до расчётного рестока (по умолчанию 1800 = 30 минут)
автоматизация перестаёт просто ждать и переходит в опрос: редко, раз в
`containers.pre_restock_interval` секунд (по умолчанию 60 = раз в минуту), пока до расчётного
рестока не останется меньше минуты, и часто (`retry_interval`, по умолчанию 10с) в последнюю
минуту и после него — так к моменту реального рестока бот уже «в процессе», а не начинает
попытки с нуля ровно в самый загруженный момент.

**Меньше сообщений игровому боту.** Пока идёт этот опрос, бот не шлёт заново команду открытия
магазина на каждой проверке — вместо этого жмёт кнопку «🔄 Обновить» на уже полученном
сообщении «раскуплены» (`containers.refresh_button`, по умолчанию «обновить»). Если такой
кнопки нет или клик не сработал — тихо откатывается на повторную отправку команды, так что
поведение не ломается, если у конкретного бота нет этой кнопки.

**Алерт владельцу за 20 минут до рестока.** За `containers.restock_alert_before` секунд до
расчётного рестока (по умолчанию 1200 = 20 минут) бот шлёт через управляющего бота разовый
алерт с оставшимся временем — «ресток через 20 мин» и т.п. Если на момент первой проверки
времени уже меньше 20 минут — в алерте будет фактический остаток, а не ровно 20. Алерт разовый
на ресток (не повторяется каждую проверку) и уважает тумблер «🔔 Алерты» аккаунта.

Какие категории вообще предлагать к покупке **для конкретного аккаунта** — тумблеры в
`⚙️ Автоматизация → 📦 Какие категории покупать` (по умолчанию все три включены); именно
они определяют, какие кнопки появятся в алерте о капче.

**Защита от перерасхода.** Перед покупками бот один раз проверяет баланс («такк») и по
ходу покупки категорий вычитает потраченное — не купит больше, чем реально есть очков.
Плюс страховка от бага парсинга: у каждой категории есть ожидаемый диапазон цены за 1 шт.
(`containers.price_ranges`, по умолчанию бюджетный 1.5–3М, дорогой 7–9М, донатный 7–9.5М
ТОчек) — если распознанная цена сильно выбивается из диапазона, категория пропускается
и владельцу шлётся алерт, вместо того чтобы слепо потратить неизвестную сумму.

Ручная проверка сейчас — кнопка «📦 Проверить магазин контейнеров» в «▶️ Действия».
Настройки — `settings.json → containers` (бот, команда открытия, маркеры распродано/капчи/
магазина, интервалы ретраев, порядок категорий, подписи кнопок покупки/подтверждения,
диапазоны цен).

> ⚠️ Флоу собран по скриншотам реальной покупки, без живого прогона автоматизации —
> тексты кнопок/маркеров вынесены в настройки специально, чтобы можно было донастроить
> без правки кода, если что-то не совпадёт с первого раза (как было с трейдом).

### 🔔 Алерты владельцу
Все алерты (капча в магазине контейнеров, подозрительная цена, неожиданный ответ) идут
**только через управляющего бота**, никогда от лица фарм-аккаунта: во время активной
автоматизации (крутит карточки и т.п.) фарм-аккаунт может быть ограничен Telegram в
отправке новых личных сообщений, так что слать алерт через него ненадёжно именно тогда,
когда он важнее всего. Включаются/выключаются per-аккаунт кнопкой «🔔 Алерты» в карточке
аккаунта (по умолчанию включены).

### 📣 Рассылка всем пользователям (создатель)
Тот, кто указан в `admin_ids`, видит в главном меню кнопку «📣 Рассылка всем пользователям» —
можно написать короткий текст (например, что изменилось в обновлении) и разослать его
ЛИЧНО всем владельцам аккаунтов в этом боте, с превью и подтверждением перед отправкой.
Полезно для публичных/мультипользовательских инстансов, чтобы не объяснять апдейты каждому
отдельно.

### 🎁 Ежедневная награда
Собирается автоматически **вместе с майнингом** (тот же триггер по времени, `mining_time`),
но включается отдельным тогглом `🌾 Фарм → ⚙️ Автоматизация → 🎁 Ежедневная награда`.
Шлёт «Ежедневная награда» → жмёт «Забрать ✅».

### 💬 Команды `.trade` / `.pay` прямо в переписке (модуль Автоотправка)
`📨 Автоотправка → 💬 Команды .trade/.pay в личках` (вкл по умолчанию). Аккаунт следит
за СВОИМИ же исходящими сообщениями в личных чатах: если ты (с телефона, с другого
устройства, залогиненного в тот же аккаунт) пишешь собеседнику `.trade` или
`.pay 505050`, бот сам отправляет @phonegetcardsbot `/trade @собеседник` или
`/pay @собеседник 505050` — получатель берётся из того, кому ты это написал. Если бот
в ответ попросит подтверждение кнопкой «Подтвердить» (как у `/pay`) — она нажимается
автоматически. Сообщения с игровыми ботами (карточки/рулетка) не перехватываются.
Команды и шаблоны — `settings.json → self_commands` (можно добавить свои).

## Быстрый /start
После `/start` внизу экрана закрепляется постоянная кнопка **`/start`** — не нужно
каждый раз набирать команду вручную, один тап и панель открывается заново.

## Добавить / перелогинить аккаунт

- В боте: 📋 Мои аккаунты → ➕ По номеру (api_id → api_hash → телефон → код → 2FA) или ➕ Session.
- Без бота (если сессия слетела): `python relogin.py` (останови бота перед этим).

## Автозапуск Windows

- `autostart_install.bat` — двойной клик, добавляет ярлык в «Автозагрузку» (старт в трее при входе).
- `autostart_uninstall.bat` — убрать.
